GOOGLE / LOGIN API
Trabalho acadêmico • Login real • Uma página HTML
01 / Introdução

Entrar com Google:
uma API em ação.

Como um sistema utiliza a identidade da conta Google para oferecer uma experiência de login prática.

O objetivo

Entender a comunicação entre o site e o Google na autenticação.

A demonstração

Fazer login com uma conta Google de verdade e mostrar o perfil retornado.

02 / Conceito

O que é a API de autenticação?

Usamos o Google Identity Services para pedir ao Google que identifique o usuário, sem que nosso site receba sua senha.

O site

Apresenta o botão “Entrar com Google” e recebe uma credencial de identidade.

O Google

Permite escolher a conta, processa o login e retorna um ID token.

Autenticação é diferente de acessar a caixa de entrada do Gmail. Este exemplo não lê e-mails.
03 / Funcionamento

O que acontece quando clicamos em Entrar com Google?

1

Solicitação

O usuário clica no botão oficial do Google dentro do site.

2

Identidade

O Google exibe a seleção da conta e entrega um token de identidade ao navegador.

3

Resultado

A página mostra o nome, o e-mail e a foto informados na credencial.

Em sistemas reais, um servidor precisa validar o ID token antes de conceder acesso a dados protegidos. Aqui é uma demonstração acadêmica só com frontend.
04 / Tecnologia

Como colocamos a API no nosso HTML?

Carregamos a biblioteca oficial, informamos o Client ID e pedimos para criar o botão de login.

<script src="https://accounts.google.com/gsi/client" async></script> google.accounts.id.initialize({ client_id: "SEU_CLIENT_ID", callback: receberCredencial }); google.accounts.id.renderButton(elemento, {theme:"outline",size:"large"});

Client ID identifica o aplicativo perante o Google. Não é a senha do usuário nem um segredo.

06 / Conclusão

Por que usar uma API de login?

Experiência

O usuário aproveita sua conta existente, sem cadastrar outra senha para a aplicação.

Integração

Em vez de desenvolver um provedor de identidade, integramos um serviço externo por JavaScript.

Aprendemos como a aplicação solicita uma identidade ao Google, recebe uma resposta e a apresenta ao usuário.
