O conceito

O que é uma API?

Uma interface que define como
dois sistemas se comunicam.

API = Interface de Programação de Aplicações.

Site

Pedido →← Resposta

Uma distinção importante

Identidade e permissões

AUTENTICAÇÃO

Quem é você?

Confirma a identidade
da pessoa que está entrando.

AUTORIZAÇÃO

O que você pode acessar?

Define quais dados e ações
ficam disponíveis para essa pessoa.

OAuth 2.0: padrão para conceder acesso limitado a outro sistema.
OpenID Connect (OIDC): padrão que acrescenta a identificação do usuário ao OAuth 2.0.

O serviço

Google Identity Services

Conjunto de ferramentas do Google para adicionar login ao site.

Conta existente

A pessoa usa a própria conta Google.

Senha no Google

O site não recebe a senha dessa conta.

Perfil básico

O site pode receber nome, e-mail e foto.

Esse login, por si só, não concede acesso ao Gmail ou ao Drive.

O processo

O que acontece após o clique?

01

Botão

O site inicia o login pelo componente oficial.

02

Conta Google

A pessoa escolhe uma conta e confirma sua identidade.

03

Credencial

O Google retorna um ID Token: uma credencial digital de identidade.

04

Validação

Em produção, o servidor verifica a credencial antes de liberar o acesso.

A aplicação controla o acesso depois de validar a identidade.

As credenciais

ID Token e JWT

ID TOKEN · TOKEN DE IDENTIFICAÇÃO

O que o Google entrega

Uma credencial digital que contém informações sobre a pessoa que entrou.

JWT · JSON WEB TOKEN

O formato da credencial

Um formato de token que transporta dados. No login do Google, inclui uma assinatura digital.

JSON é um formato de texto que organiza informações em campos e valores.
Exemplo: "name": "Ana" relaciona o campo nome ao valor Ana.

Fonte: padrão JWT (RFC 7519)

A estrutura

As três partes do JWT

No ID Token do Google, as partes são separadas por pontos.

01

Header

Cabeçalho

Indica o algoritmo usado para assinar o token.

02

Payload

Conteúdo

Reúne os dados da identidade e da validade do token.

03

Signature

Assinatura digital

Permite verificar a origem e se os dados foram alterados.

Algoritmo é o método de cálculo usado na assinatura digital.

Os campos

O que significa sub?

sub vem de subject e identifica a conta à qual o token se refere.

Identificador da conta

No Google, é um identificador único e estável para aquela conta.

O sistema usa esse valor para reconhecer a mesma pessoa, mesmo que o e-mail mude.

EXEMPLO FICTÍCIO DE DADOS
{
  "name": "Ana Exemplo",
  "email": "ana@example.com",
  "sub": "1234567890"
}

name = nome · email = endereço de e-mail
sub = identificador da conta

Segurança

Como o servidor valida o token

O servidor é o sistema que verifica a credencial e protege os dados do site.

Assinatura

Confirma a origem e a integridade dos dados.

Emissor · iss

Quem emitiu a credencial. Neste caso, o Google.

Audiência · aud

Para qual site ou aplicativo o token foi emitido.

Expiração · exp

Até quando a credencial pode ser aceita.

Após a validação, a sessão mantém o usuário identificado entre solicitações ao site. As permissões definem o que ele pode acessar.

Fonte: documentação oficial do Google
