POR QUE ESSA INTEGRAÇÃO?

O Google cuida da conta.
O site cuida da experiência.

01

Entrada mais simples

Usar uma conta existente reduz o cadastro e evita criar outra senha para este site.

02

Identidade consistente

Após validar o token no servidor, o site usa o campo sub para reconhecer a mesma conta.

03

Integração pronta

A biblioteca oficial oferece o botão e a escolha de conta; a aplicação recebe a credencial e monta a interface.

Login não é permissão para ler Gmail ou Drive. O site continua responsável por validar credenciais, criar sessões e definir o acesso aos seus recursos.

01 / GOOGLE + SITE

Carregar o serviço

O site carrega a biblioteca oficial. O endereço pertence ao Google; a função de carregamento e o tratamento de falhas pertencem ao site.

Ver trecho de demo/script.js
function loadGoogleSDK() {
  if (window.google?.accounts?.id) return Promise.resolve();
  if (sdkPromise) return sdkPromise;
  sdkPromise = new Promise((resolve, reject) => {
    const sdk = document.createElement('script');
    sdk.src = 'https://accounts.google.com/gsi/client?hl=pt-BR';
    sdk.async = true;
    const timer = setTimeout(() => finish(false), 15000);
    let settled = false;
    function finish(ok) {
      if (settled) return;
      settled = true;
      clearTimeout(timer);
      sdk.onload = sdk.onerror = null;
      if (ok) resolve();
      else { sdk.remove(); reject(new Error('Não foi possível carregar o Google.')); }
    }
    sdk.onload = () => finish(Boolean(window.google?.accounts?.id));
    sdk.onerror = () => finish(false);
    document.head.append(sdk);
  }).catch(error => { sdkPromise = null; throw error; });
  return sdkPromise;
}
02 / GOOGLE

Preparar o botão oficial

initialize associa o Client ID ao site. renderButton desenha o botão oficial; o Google conduz a escolha da conta.

Ver trecho de demo/script.js
function renderGoogleButton() {
  if (!initialized) {
    google.accounts.id.initialize({
      client_id: CLIENT_ID,
      callback: receiveCredential,
      auto_select: false,
      ux_mode: 'popup'
    });
    initialized = true;
  }
  $('googleButton').replaceChildren();
  google.accounts.id.renderButton($('googleButton'), {
    theme: 'outline', size: 'large', width: 240, locale: 'pt-BR'
  });
}
03 / RESPOSTA

Receber a credencial

O Google chama o callback com um ID Token. decodeProfile apenas lê e confere campos; não valida a assinatura nem cria uma sessão.

Ver trecho de demo/script.js
function receiveCredential(response) {
  try {
    const profile = decodeProfile(response.credential);
    showProfile(profile, 'google');
  } catch {
    $('loginStatus').textContent = 'Não foi possível ler a credencial. Tente novamente.';
  }
}
04 / SITE

Mostrar os dados na tela

O site usa textContent para mostrar nome e e-mail, escolhe a foto e muda a interface. Nenhum recurso privado é protegido por esta tela.

Ver trecho de demo/script.js
function showProfile(profile, mode) {
  profileVisible = true;
  $('profileName').textContent = profile.name;
  $('profileEmail').textContent = profile.email;
  $('profileInitials').textContent = profile.name.trim().split(/\s+/)
    .slice(0, 2).map(part => Array.from(part)[0] || '').join('');
  $('modeBadge').textContent = mode === 'demo'
    ? 'Simulação • perfil fictício'
    : 'Google • perfil recebido, sem validação no servidor';
  setPhoto(profile.picture, mode);
  $('loginView').hidden = true;
  $('dashboard').hidden = false;
  $('dashboardTitle').focus();
}

06 / SITE

Sair do exemplo

O site limpa os dados da interface e evita a seleção automática. Isso não desconecta a conta Google de outros serviços.

Ver trecho de demo/script.js
$('logout').addEventListener('click', () => {
  profileVisible = false;
  photoVersion++;
  $('profilePhoto').onload = $('profilePhoto').onerror = null;
  $('profilePhoto').removeAttribute('src');
  $('profileName').textContent = $('profileEmail').textContent = '';
  $('profileInitials').textContent = $('modeBadge').textContent = '';
  $('dashboard').hidden = true;
  $('loginView').hidden = false;
  window.google?.accounts?.id?.disableAutoSelect();
  $('loginStatus').textContent = 'Perfil removido desta página. Sua conta Google continua conectada ao Google.';
  $('demoLogin').focus();
});

O que falta para uma autenticação de produção?

Enviar a credencial ao servidor por HTTPS; validar assinatura, emissor (iss), audiência (aud) e expiração (exp); associar o sub à conta local e criar uma sessão segura. Ler o payload no navegador não comprova sua autenticidade.
